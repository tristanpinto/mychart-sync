Chartstash: local data handling

Example disclosure for your own app registration. Review and adapt before use.

Chartstash retrieves records you authorize from your healthcare providers and stores them as local files. MyChart passwords are entered on the hospital's login page; local OAuth tokens allow subsequent access. Optional Tidepool API login stores a password locally. File permissions are not encryption.

There is no Chartstash-hosted data service. Your backup, file-sync, and agent settings determine whether another service receives the files. You are responsible for securing credentials and deciding who can read the records.

Outputs may be incomplete or inaccurate. This tool does not provide medical advice and must not be used to automate treatment. See the MIT license for the software warranty disclaimer.
